# 📖 Glossário — sem jargão

Aqui estão as palavras mais frequentes do TDA, explicadas antes de entrar em detalhes técnicos.

| Termo | Significado |
| --- | --- |
| **ADR** | Registro de uma decisão arquitetural e seus motivos |
| **Agent** | Serviço do Companion que opera no computador local |
| **ASR** | Reconhecimento automático de fala, que transforma áudio em texto candidato |
| **Assembly** | Composição de várias gravações para a mesma sessão |
| **Auth** | Autenticação: identificar quem entrou |
| **Audience** | Público ou pessoas autorizadas a receber uma informação |
| **Capability** | Permissão específica para uma ação e seu escopo |
| **Campanha** | Jornada narrativa de RPG e fronteira contextual de dados |
| **Canon** | Informação estabelecida da história após revisão adequada |
| **CI/CD** | Verificações automatizadas / fluxo controlado de entrega |
| **Companion** | Programa Windows para processamento pesado local |
| **Craig** | Fonte externa de gravações vinculada ao Discord |
| **Edit** | Ferramentas autorizadas de produção/revisão editorial |
| **Entity** | Personagem, lugar, item, organização, facção e outras entidades |
| **Evidence** | Fonte que sustenta uma afirmação; não equivale a canon |
| **Lore** | Conteúdo narrativo sobre um universo ou personagem |
| **Lembra** | Galeria compartilhada de referências visuais |
| **MSI** | Instalador Windows do Companion |
| **NPC** | Personagem não jogável |
| **PC** | Personagem de um jogador |
| **PR** | Pull request: proposta de mudança a ser revisada |
| **Provenance** | Origem e histórico verificável da informação |
| **Publication** | Publicação editorial ou deploy, conforme contexto; atos diferentes |
| **RBAC** | Controle de acesso baseado em papéis |
| **Receipt** | Comprovante de uma operação/entrega exata |
| **Review** | Revisão humana ou de versão |
| **RLS** | Políticas do PostgreSQL de restrição de linhas |
| **R2** | Provedor atual do Media Storage |
| **Run** | Resultado preservado de uma tentativa de processamento |
| **Runtime** | Modelos e dependências do motor de ASR |
| **Sessão** | Encontro da campanha; não confundir com sessão de login |
| **Stable / RC** | Estágios/canais de distribuição de software |
| **Supabase** | Provedor de banco PostgreSQL/Auth atual |
| **Whisper e Qwen** | Motores de reconhecimento de fala |
| **World Explorer** | Mapa visual de entidades, chamado Ecos da Jornada |

## Palavras ambíguas

**Publicação** pode ser tornar um resumo público, fazer deploy Web ou lançar MSI — com processos independentes. **Sessão** pode ser encontro de RPG ou autenticação. **Wiki** aqui é documentação do software, não o banco narrativo da campanha.

**Contratos detalhados:** [Modelo de dados](https://github.com/Faysk/tda/blob/main/docs/data-model.md), [Canon/revisão](https://github.com/Faysk/tda/blob/main/docs/domains/canon-review.md) e [Estado documental](https://github.com/Faysk/tda/blob/main/docs/documentation/README.md).
